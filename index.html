Project G.I.G

Gefunden ist Gefangen

Project G.I.G bringt das klassische Versteck- und Fangspiel mit einer Live-Karte auf dem Handy nach draußen. Eine Person öffnet eine Lobby, alle anderen treten mit einem 5-stelligen Code bei.

  • Jäger gegen Versteckte in einer Spielzone auf der echten Karte
  • Versteckte sind nur bei regelmäßigen Pings sichtbar
  • Power-ups aus Versorgungskisten: Tarnung, Köder, Späher, Radar
  • Kein Konto, keine Werbung

Jetzt im Browser spielen

Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Bald auch bei Google Play.
